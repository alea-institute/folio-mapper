# Seed: Demo mode for non-litigation practice areas

The initial demo-mode rollout covers the existing 10 exemplars, which skew litigation-heavy (personal injury, commercial litigation, patent law, etc.). FOLIO also covers transactional and regulatory domains — M&A, IP licensing, securities compliance, employment, real estate transactions, regulatory filings, etc. — that would broaden the audience for the demo.

## Why wait

- Lean exemplar set doesn't currently include these areas; demo mode is a *parallel payload* per existing exemplar, so transactional demos require transactional exemplars first.
- FOLIO branch depth in transactional areas is less well understood — the spike on PI tells us nothing about whether M&A clauses yield 1:4-1:5 fan-out.
- Sales/conference narrative for v1 is "the system invites your expertise" using litigation scenarios that resonate with most lawyers. Transactional rollout serves a different audience (corporate counsel, regulatory).

## Trigger

When the lean exemplar set is expanded to include transactional/regulatory practice areas — or when a specific audience (e.g., corporate counsel demo, regulatory conference) creates the need — revisit:

1. Which transactional areas have sufficient FOLIO density (run a coverage probe before drafting items)
2. Whether item shape differs (transactional inputs are often clause-shaped, not narrative-shaped)
3. Whether the "ambiguity invites curation" narrative reads differently for transactional users (who may want more determinism, not less)
